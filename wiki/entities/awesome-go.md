# awesome-go

## 概览
`awesome-go` 是社区驱动的 Go 开源项目精选索引，按领域组织框架、库与工具，帮助开发者快速缩小技术选型范围。

## 关键事实
- 原始来源：[[raw/awesome-go.md]] 与 [[wiki/sources/awesome-go|来源摘要]]。
- 核心机制：通过仓库测试与 GitHub Actions 检查链接可用性、成熟度与仓库活跃度。
- 生态角色：作为 Go 生态“候选池”，更适合初筛，不直接替代性能基准与生产验证。
