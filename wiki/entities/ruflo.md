# ruflo

## 概览
ruflo 是面向 Claude 生态的多智能体编排平台，主打跨会话记忆、多 Agent 协同与工程化自动化。

## 关键事实
- 主要来源：[[raw/ruflo.md]] 与 [[wiki/sources/ruflo|来源摘要]]。
- 技术栈特征：TypeScript、MCP server、多 Agent Swarm、联邦通信（federation）。
- 风险信号：当前版本处于 alpha 阶段，功能强但复杂度高。
