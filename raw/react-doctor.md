# millionco/react-doctor

### 🎯 一句话定位
React Doctor 是一个用于分析 React 代码质量的工具，通过提供健康分数和可操作的诊断建议，帮助开发者提升代码质量，并能集成到 AI 编码助手和 CI/CD 流程中。

### ⚡ 核心功能（3~5条）
*   **代码健康评分与诊断：** 为 React 代码库提供一个 0-100 的健康分数，并列出在状态与副作用、性能、架构、安全和可访问性方面的具体问题。
*   **AI 编码助手集成：** 可以安装并配置，以训练 AI 编码助手遵循 React 最佳实践，减少生成不良代码。
*   **CI/CD 集成：** 提供 GitHub Actions 复合动作，可自动在 PR 中发布代码质量反馈和分数。
*   **框架兼容性：** 支持 Next.js, Vite, 和 React Native 等主流框架。

### 🎭 适用场景
*   **个人开发者：** 快速评估和改进自己的 React 项目代码质量。
*   **团队协作：** 在团队内部建立统一的代码质量标准，并通过 CI/CD 自动化检查。
*   **AI 辅助开发：** 希望利用 AI 提升开发效率，同时确保 AI 生成代码的质量。
*   **项目迁移与重构：** 在进行大型项目重构或迁移时，作为质量评估的辅助工具。

### ✅ 是否值得深入研究
**值得。** 该项目拥有较高的 Star 数（10513），表明其在社区中受到广泛关注和认可。其核心功能直接解决了开发者在 React 开发中普遍遇到的代码质量问题，并且提供了与 AI 助手和 CI/CD 集成的能力，具有很高的实用价值和前瞻性。

### ⚠️ 主要缺点或风险
*   **移除 Knip 集成：** README 中提到已移除对 Knip 的集成，如果开发者依赖此功能进行死代码检测，需要单独运行 `knip`。
*   **AI 集成配置：** 虽然支持多种 AI 助手，但具体的集成配置和效果可能需要一定的学习成本。
*   **依赖更新：** 作为一个相对活跃的项目，需要关注其依赖和规则的更新，以保持最佳兼容性和安全性。

### 🔗 与同类项目对比
与 ESLint、Prettier 等传统的代码风格检查和格式化工具相比，React Doctor 更侧重于**代码的整体健康度、性能、架构和安全性**，提供了一个更宏观的评估维度。它不仅仅是检查语法或风格，而是深入到 React 特有的最佳实践和潜在问题。同时，其与 AI 编码助手的集成是其独特之处，这是许多传统 Linter 所不具备的。
