# martinopiaggi/summarize

### 🎯 一句话定位
这是一个基于 `yt-dlp` 和 `Whisper` 的多源视频转录与 AI 总结工具，旨在通过统一接口将各类社交媒体视频转化为结构化的知识摘要。

### ⚡ 核心功能
1. **全平台支持**：集成 `yt-dlp` 和 `Cobalt`，支持 YouTube、TikTok、Instagram、X、Reddit 等主流平台的音视频下载。
2. **灵活转录**：支持调用本地或云端 Whisper 模型进行语音转文字，并具备缓存机制以节省重复处理成本。
3. **多模型适配**：兼容所有 OpenAI 兼容的 LLM 接口，支持用户接入本地大模型（如 Ollama）或商业 API。
4. **多端交互**：提供 CLI 命令行工具、Streamlit Web GUI 以及 Docker 一键部署方案，甚至包含 Agent 技能定义。

### 🎭 适用场景
- **知识管理**：快速获取长视频或社交媒体短视频的核心观点，构建个人知识库。
- **内容创作**：为视频内容制作脚本摘要、博客文章或社交媒体推文。
- **自动化办公**：通过 Agent 自动化处理来自不同渠道的视频信息流，实现“视频到笔记”的自动化工作流。

### ✅ 是否值得深入研究
**值得。** 该项目架构清晰，模块化程度高（特别是 `downloaders` 和 `transcription` 的解耦），非常适合作为学习“如何构建 AI 视频处理流水线”的参考案例。对于需要快速搭建私有化视频总结工具的开发者，它是一个极佳的脚手架。

### ⚠️ 主要缺点或风险
1. **依赖稳定性**：高度依赖 `yt-dlp` 和 `Cobalt` 等第三方下载库，若这些服务接口更新或失效，项目维护成本较高。
2. **性能瓶颈**：本地运行 Whisper 转录长视频对显存和 CPU 要求较高，且缺乏分布式处理能力。
3. **法律与合规**：批量下载社交媒体视频可能触及平台服务条款（ToS），在商业化使用时需评估版权风险。

### 🔗 与同类项目对比
- **vs. NotebookLM**：NotebookLM 是 Google 的闭源产品，侧重于深度文档交互；本项目是开源的，侧重于“视频转录”这一特定环节的自动化。
- **vs. Video-to-Markdown 类工具**：本项目通过集成 `Cobalt` 和 `yt-dlp` 实现了更广泛的平台覆盖，且架构上更偏向于开发者工具，而非单纯的 SaaS 产品。
- **优势**：支持本地化部署和 Agent 集成，隐私性更好，且不依赖单一平台的 API 限制。
