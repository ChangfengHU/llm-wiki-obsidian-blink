# luoluoluo22/jianying-editor-skill

### 🎯 一句话定位
这是一个通过 AI Agent 自动化驱动剪映（CapCut）桌面版进行视频剪辑的 Python 工具库，旨在将自然语言指令转化为剪映的时间轴操作。

### ⚡ 核心功能
1. **自动化编排**：支持素材导入、自动对齐、添加转场、特效及关键帧动画。
2. **AI 协同工作流**：集成文案生成、TTS 配音及自动字幕对齐，实现从脚本到视频的一键式处理。
3. **录屏与视觉增强**：具备自动录屏及鼠标点击位置的缩放、红圈标记等后期处理功能。
4. **多模型适配**：支持接入 Antigravity、Cursor、Claude Code 等主流 AI 编程助手，实现“对话式剪辑”。

### 🎭 适用场景
- **批量化内容生产**：如影视解说、知识科普、营销短视频的快速批量剪辑。
- **自动化录屏教程**：需要对操作演示进行自动缩放、标注和后期剪辑的场景。
- **AI 代理开发**：作为构建“视频生成 Agent”的底层 Skill 模块，适合开发者集成到自己的自动化工作流中。

### ✅ 是否值得深入研究
**值得。** 对于想了解如何通过代码控制 GUI 软件（RPA）以及如何将 LLM 与本地桌面应用结合的开发者来说，该项目具有极高的参考价值。它展示了如何通过解析剪映的工程文件或模拟 UI 操作来实现复杂逻辑。

### ⚠️ 主要缺点或风险
1. **版本依赖强**：目前仅完美支持剪映 5.9 及以下版本，新版本更新可能导致脚本失效。
2. **稳定性挑战**：基于 UI 自动化（RPA）的逻辑，容易受到系统弹窗、分辨率变化或软件 UI 改动的影响。
3. **功能局限性**：无法调用剪映内部需要 GPU 实时渲染的 AI 功能（如智能抠图、人像美颜）。
4. **维护成本**：剪映官方更新频繁，该项目属于“逆向工程”性质，长期维护压力较大。

### 🔗 与同类项目对比
- **vs 传统剪辑软件 API**：剪映官方未提供公开 API，该项目通过 RPA 模拟操作，比直接调用 FFmpeg 等底层库更直观，但不如专业视频编辑 SDK 稳定。
- **vs 自动化脚本（如 AutoHotkey/PyAutoGUI）**：该项目封装了针对剪映的特定业务逻辑（如字幕对齐、特效搜索），比通用的鼠标点击脚本更具“语义理解”能力，更适合 AI Agent 调用。
- **vs 云端视频生成平台**：该项目利用本地剪映的强大渲染能力，比纯云端 API 方案更节省成本，且生成的视频更符合剪映生态的审美。
