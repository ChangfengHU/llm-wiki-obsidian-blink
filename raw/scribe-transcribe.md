# jun7799/scribe-transcribe

### 🎯 一句话定位
这是一个基于 MITM（中间人攻击）技术实现微信视频号视频下载，并集成 `faster-whisper` 实现本地音视频自动转写字幕的自动化工具。

### ⚡ 核心功能
1. **视频号拦截下载**：通过 Go 编写的 MITM 代理服务，在微信客户端注入下载逻辑，获取视频源文件。
2. **本地语音转写**：集成 `faster-whisper` 模型，支持离线将视频音频转化为高精度文字。
3. **多格式导出**：支持将转写结果自动导出为 SRT 字幕文件或 TXT 纯文本。
4. **CLI 交互界面**：提供 Python 命令行工具，支持一键启动服务、批量处理本地文件及任务管理。

### 🎭 适用场景
- **自媒体创作者**：需要快速获取视频号素材并提取文案进行二次创作。
- **内容整理者**：需要将视频号中的讲座、访谈等长视频快速转化为文字稿进行归档。
- **技术学习者**：研究 MITM 代理拦截、音视频处理流程及 AI 模型本地化部署的开发者。

### ✅ 是否值得深入研究
**值得作为技术参考，但不建议作为生产力工具直接使用。**
该项目架构清晰（Go 处理网络层，Python 处理逻辑层），适合学习如何将不同的技术栈组合解决实际问题。但由于其依赖微信客户端的特定版本和网络环境，维护成本较高。

### ⚠️ 主要缺点或风险
1. **高维护门槛**：微信视频号的加密协议和接口经常更新，MITM 方案极易失效，需要频繁跟进上游核心库。
2. **配置复杂**：用户需要手动配置手机代理、安装证书，且涉及网络拦截，对小白用户不友好。
3. **合规风险**：该工具涉及绕过平台限制下载内容，存在潜在的法律与平台封号风险。
4. **性能开销**：本地运行 `faster-whisper` 对电脑显存（GPU）或 CPU 有一定要求，低配机器转写速度较慢。

### 🔗 与同类项目对比
- **对比“网页版/插件类下载器”**：本项目通过代理拦截，获取的是原始视频流，清晰度更高且更稳定，但配置难度远高于浏览器插件。
- **对比“在线转写服务”**：本项目完全本地化，保护隐私且无调用费用，但需要自行配置环境，不像在线工具（如飞书妙记、通义听悟）那样即开即用。
- **对比“通用视频下载工具（如 yt-dlp）”**：yt-dlp 对主流平台支持极好，但对微信视频号这种封闭生态支持有限，本项目填补了这一特定领域的空白。
