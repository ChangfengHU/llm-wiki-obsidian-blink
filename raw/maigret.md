🎯 **一句话定位**
【FACT】Maigret 是一个只需输入目标用户名，即可在 3000 多个网站上自动搜集并生成目标人物数字档案的开源 OSINT（开源情报）工具。
*来源：GitHub README 顶部描述*

⚡ **核心功能**
【FACT】
1. **全网账号检索**：无需 API Key，通过用户名在 3000+ 网站（含 Tor/I2P 网站）中搜寻目标账号。
2. **深度信息提取与递归搜索**：从个人主页和 API 提取关联信息，并利用新发现的 ID 自动进行下一轮深度搜索。
3. **反爬与审查绕过**：内置机制检测并部分绕过网站封锁、审查和 CAPTCHA 验证。
4. **多维度报告生成**：支持生成 HTML、PDF、XMind 思维导图、交互式图表（Graph）以及多种机器可读格式（JSON/CSV）。
5. **AI 辅助分析**：可选 `--ai` 模式，通过对接 OpenAI 兼容接口，将海量原始数据汇总为简短的调查摘要。
*来源：GitHub README / Main features*

🎭 **适用场景**
【INFERENCE】
- **红队/渗透测试前期的信息收集**：安全工程师在社工阶段通过目标常用用户名挖掘其注册过的各类平台，寻找密码复用或社交工程学突破口。
- **网络犯罪调查/黑产溯源**：安全研究员或执法人员追踪特定网络身份的数字足迹，描绘人物画像及社交关系网（SOCMINT）。
- **个人隐私暴露面自查**：普通用户或企业高管检查自己的常用 ID 在互联网上泄露了多少隐私信息，进行自我数字足迹清理。

**判断依据**：基于 README 中列出的 Topics（blueteam, pentesting, investigation, socmint）以及该项目被 Social Links Crimewall 等专业商业情报调查工具集成的客观事实。
**confidence**：high

✅ **是否值得深入研究**
【INFERENCE】
**结论**：**值得**

**理由**：
- **信号1：行业认可度极高**。拥有近 2.6 万 Stars，且被 Social Links 等专业商业 OSINT 工具作为底层依赖，证明其工程质量和数据准确性经受住了商业化考验。
- **信号2：功能深度超越同类**。大多数同类工具仅做 HTTP 状态码探测（看账号存不存在），而它集成了 `socid_extractor` 进行页面内容解析，并支持“递归搜索”和“AI 总结”，自动化程度极高。
- **信号3：维护机制优秀**。实现了网站数据库每日自动从 GitHub 更新（Auto-updated site database），优雅地解决了爬虫类工具最头疼的“规则过期失效”痛点。

**confidence**：high

⚠️ **主要缺点或风险**
【INFERENCE】
- **缺点1：强依赖目标网站的结构稳定性**。尽管有自动更新机制，但 3000+ 网站的页面改版或反爬策略升级（如强制高等级 Cloudflare 验证）仍会导致部分检测节点随时失效。
- **缺点2：误报与数据污染（重名问题）**。用户名具有非排他性，工具收集到的档案极大概率混杂了世界上多个使用同一 ID 的不同人的信息。
- **缺点3：法律与合规风险**。在未授权情况下对他人进行深度数字足迹画像，在严格的数据保护法规（如 GDPR）辖区内极易触碰隐私红线。

**对使用场景的影响**：在实际使用中，输出的报告不能直接作为最终结论，必须经过人工或 AI 的二次交叉验证清洗；企业内部使用时需严格评估合规性。

🔗 **与同类项目对比**
【INFERENCE】

**对标项目**：Sherlock, WhatsMyName

| 维度 | 本项目 (Maigret) | Sherlock | WhatsMyName |
|-----|--------|----------|----------|
| **定位** | 深度 OSINT 档案收集与分析 | 轻量级用户名存在性检测 | 用户名枚举规则与数据集 |
| **核心优势** | 支持内容提取、递归搜索、多格式报告、AI总结 | 极度知名，运行速度快，使用简单 | 社区驱动的庞大且准确的规则库，极易被其他工具集成 |
| **核心劣势** | 运行较重，全量扫描耗时较长，依赖复杂 | 仅检测账号是否存在，不抓取页面深度信息 | 本质是数据集/轻量脚本，缺乏自动化分析与报告生成能力 |

**对比依据**：基于 GitHub 开源 OSINT 领域的常识。Sherlock 也是该项目 README Topics 中明确提及的标签，两者经常被拿来比较；Maigret 实际上是在 Sherlock 的概念上做了深度强化（强调 Extracts info 和 Recursive search）。
**confidence**：high
