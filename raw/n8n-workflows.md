# Zie619/n8n-workflows

### 🎯 一句话定位
这是一个由社区驱动的 **n8n 自动化工作流资源库**，现已转型为集成 AI 安全扫描工具（AI-BOM）的自动化生态平台。

### ⚡ 核心功能
1. **海量工作流库**：提供超过 4,300 个 n8n 自动化工作流模板，涵盖多种集成场景。
2. **AI 安全扫描 (AI-BOM)**：内置安全工具，用于检测 n8n 工作流中的硬编码密钥、不安全的 AI 代理及潜在的漏洞。
3. **在线检索与部署**：提供在线浏览界面和配套的 Docker/Kubernetes 部署方案，方便快速搭建自动化环境。
4. **AI 技术栈集成**：包含针对 ComfyUI 等 AI 服务的特定工作流及快速部署脚本。

### 🎭 适用场景
- **n8n 开发者**：寻找特定业务逻辑（如 API 集成、数据处理）的现成模板以加速开发。
- **企业安全审计**：需要对内部 n8n 自动化流程进行 AI 安全合规性检查（符合 EU AI Act 等要求）的团队。
- **自动化运维人员**：希望快速搭建 n8n 环境并集成 AI 工作流的 DevOps 工程师。

### ✅ 是否值得深入研究
**非常值得。** 尤其是对于正在使用 n8n 进行企业级 AI 自动化部署的团队，该项目不仅是“模板库”，其配套的 **AI-BOM 安全扫描工具** 具有极高的实用价值，能有效规避自动化流程中的安全隐患。

### ⚠️ 主要缺点或风险
1. **项目重心偏移**：项目目前被原作者用于推广其商业/开源安全工具（AI-BOM），工作流模板的更新频率可能不如早期活跃。
2. **质量参差不齐**：由于是社区收集，部分工作流可能存在过时、配置复杂或依赖特定版本 n8n 的问题。
3. **安全依赖**：过度依赖其提供的安全扫描工具可能存在隐私风险，需评估其扫描逻辑是否会将工作流数据上传至第三方服务器。

### 🔗 与同类项目对比
- **vs n8n 官方模板库**：官方库更权威、稳定，但该项目规模更大、覆盖面更广，且增加了官方库不具备的“安全审计”功能。
- **vs 其他 GitHub 自动化仓库**：大多数同类项目仅提供代码片段，而该项目提供了完整的 Docker 编排、K8s 配置及配套的 CLI 安全工具，工程化程度更高。
