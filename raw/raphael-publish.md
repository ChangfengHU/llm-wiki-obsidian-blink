### 🎯 一句话定位
专为微信公众号和内容创作者打造的纯前端 Markdown 排版工具，核心解决跨平台富文本粘贴、样式美化及微信平台图片防盗链/样式兼容痛点。

### ⚡ 核心功能
1. **富文本“魔法粘贴”**：基于 `turndown` 深度定制，无缝解析飞书、Notion、Word 甚至网页复制的内容，自动剥离冗余标签并转为纯净 Markdown。
2. **微信 DOM 深度兼容**：一键复制到公众号时，外链图片自动转 Base64（绕过微信“此图片来自第三方”拦截），并在底层重塑 DOM，防止列表和表格在微信中塌陷。
3. **30套开箱即用的高定主题**：内置 Notion、Medium、少数派等高质量排版样式，涵盖背景、字体、代码块，告别需手动调 CSS 的繁琐。
4. **多图网格排版**：支持多图并排布局，并通过定制引擎确保在微信中完美渲染不折断。

### 🎭 适用场景
- **自媒体/公众号运营**：在 Notion/飞书/Typora 中完成初稿，直接复制粘贴到该工具，一键渲染并推送到微信后台，无需重新排版。
- **技术博主**：习惯使用纯 Markdown 写作（尤其包含大量代码块），需要快速转换为微信公众号友好的格式。
- **轻量级文档导出**：需要将 Markdown 快速套用精美模板，并导出为 PDF 或 HTML 存档的文字工作者。

### ✅ 是否值得深入研究
**值得（强烈推荐前端工程师阅读源码）**。
- **业务价值**：切入点极佳，把“微信排版”这个恶心但高频的痛点解决得很优雅。
- **技术价值**：代码结构清晰（React + Vite）。其 `src/lib/htmlToMarkdown.ts`（富文本 AST 解析净化）和 `src/lib/wechatCompat.ts`（微信特定 DOM/CSS 兼容黑科技）非常值得学习，展示了如何处理复杂的剪贴板劫持与跨平台渲染差异。

### ⚠️ 主要缺点或风险
1. **剪贴板容量瓶颈**：通过 Base64 转换图片绕过防盗链是神来之笔，但如果文章包含大量高清大图，生成的 Base64 字符串极大，可能导致浏览器卡顿或微信后台粘贴失败。
2. **微信规则依赖风险**：强依赖微信现有的富文本编辑器渲染逻辑（`wechatCompat`），若微信后台升级或修改了 DOM 过滤白名单，部分排版可能会突然失效。
3. **纯静态无云端**：作为一个纯前端 SPA，目前缺乏云端同步、草稿保存和历史版本管理，刷新或清缓存可能丢失未导出的内容。

### 🔗 与同类项目对比
- **对比 Markdown Nice (mdnice)**：mdnice 是老牌霸主，支持丰富的自定义 CSS 生态。但 Raphael Publish 胜在 **UI 更现代**、**高阶主题开箱即用**（无需懂 CSS），以及**跨平台富文本粘贴净化更强**（mdnice 处理飞书/Notion 复制内容时常有冗余标签）。
- **对比 秀米/135等传统排版器**：降维打击。放弃了拖拽式排版的臃肿，用 Markdown 保证了内容的纯粹性，适合重文字、重逻辑的创作者。
