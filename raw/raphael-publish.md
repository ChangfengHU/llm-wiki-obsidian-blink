### 🎯 一句话定位
专为微信公众号创作者打造的现代化 Markdown 排版引擎，完美解决富文本粘贴、多端样式兼容及图片防盗链等微信排版痛点。

### ⚡ 核心功能
*   **“魔法粘贴”自动净化**：底层基于 `turndown`，支持从 Notion、飞书等直接复制富文本，粘贴瞬间自动转换为纯净 Markdown，支持直接粘贴截图。
*   **微信生态深度防御**：外链图片自动转 Base64 破解微信防盗链（告别“此图片来自第三方”）；底层重写 DOM（`wechatCompat.ts`）解决列表和表格在微信中塌陷的问题。
*   **开箱即用的高定主题**：内置 30 套高质量 CSS 主题（如 Notion风、少数派风等），细化到代码块、引用、表格的独立设计，一键切换。
*   **多端预览与导出**：支持手机/平板/PC实时响应式预览，并提供 PDF 和 HTML 导出能力。

### 🎭 适用场景
*   **公众号创作者**：习惯使用 Markdown 写作，需要快速将内容美化并一键发布到微信公众号的自媒体人。
*   **跨平台内容搬运工**：需要将飞书、Notion、知乎等平台的文章无损、免排版搬运到微信公众号的运营人员。
*   **前端开发者**：需要学习如何使用 `markdown-it` 深度定制渲染规则、或处理富文本与剪贴板转换的开发者。

### ✅ 是否值得深入研究
**值得（针对前端开发者）**。
理由：项目技术栈现代（React 18 + Vite + TS + Tailwind），工程化规范完整（包含 Vitest 和 Playwright E2E 测试）。其核心价值在于对 `markdown-it` 的深度定制和 `wechatCompat.ts` 中的微信 DOM 兼容处理，是学习**富文本剪贴板处理**、**Markdown AST 解析与渲染**的优秀实战源码。

### ⚠️ 主要缺点或风险
1.  **Base64 图片体积风险**：将外链图片全量转为 Base64 虽然解决了防盗链，但在多图或高清大图场景下，会导致生成的 HTML 体积暴增，极易触发微信公众号后台的字数/代码体积限制。
2.  **高度依赖微信机制**：核心卖点基于微信公众号当前的编辑器缺陷。若微信官方未来升级编辑器原生支持 Markdown，该项目的部分核心价值将被削弱。
3.  **纯前端无状态**：作为一个纯静态工具，缺乏云端同步或多版本历史记录功能，更适合作为“排版中转站”而非“主力内容管理库”。

### 🔗 与同类项目对比
*   **对比 Markdown Nice (mdnice)**：mdnice 是该领域的老牌霸主，主题生态更丰富，但目前商业化较重且 UI 偏传统。本项目 UI 更加现代化，且主打“魔法粘贴”（飞书/Notion无缝接入），体验更轻量纯粹。
*   **对比 Doocs/md**：Doocs/md 同样是优秀的开源微信排版工具。本项目的差异化优势在于**图片 Base64 自动转换**（无需繁琐配置图床即可解决防盗链）以及更精细的微信 DOM 兼容处理（如支持多图网格排版不断裂）。
