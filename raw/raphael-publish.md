### 🎯 一句话定位
【FACT】专为微信公众号和内容创作者打造的现代 Markdown 排版引擎，支持将富文本无缝转为 Markdown，并渲染为兼容微信的高定样式后一键发布。
*来源：GitHub README*

### ⚡ 核心功能
【FACT】
1. **魔法粘贴（富文本净化）**：基于 `turndown`，支持从飞书、Notion 等平台复制富文本或直接粘贴截图，自动转换为纯净 Markdown。
2. **一键复制到公众号**：底层重塑 DOM（`wechatCompat.ts`），自动将外链图片转为 Base64 绕过微信防盗链，并防止列表/表格样式在微信中塌陷。
3. **30套预设高定主题**：内置微信原生、Notion、少数派等多种独立设计的主题，一键切换。
4. **多图网格排版**：支持兼容微信公众号的多图并排布局，不折行。
5. **多端实时预览与导出**：支持手机/平板/PC三端视图切换，支持导出 PDF/HTML。
*来源：GitHub README / `package.json` / 代码结构*

### 🎭 适用场景
【INFERENCE】
1. **微信公众号日常运营**：创作者在 Notion 或飞书中写完草稿后，直接复制粘贴到该工具，选好主题后一键同步到公众号，无需手动排版和处理图片防盗链。
2. **跨平台分发排版**：习惯使用纯 Markdown 写作的博主，需要将文章快速渲染成带样式的富文本，以便分发到知乎、百家号等不支持原生 Markdown 的平台。

*判断依据：README 中明确指出的“从飞书/Notion复制”、“外链图片自动转 Base64”、“底层 DOM 重塑”等专门针对微信和跨平台富文本编辑器的痛点特性。*
*confidence：high*

### ✅ 是否值得深入研究
【INFERENCE】
**结论：值得**（特别是对前端富文本处理、剪贴板交互感兴趣的开发者）

**理由：**
- **信号1：优秀的剪贴板劫持与解析实现**。源码中的 `htmlToMarkdown.ts` 结合 `turndown` 处理复杂富文本粘贴，是处理前端 `paste` 事件、清洗脏 DOM 的绝佳参考。
- **信号2：解决特定平台的 DOM 兼容黑魔法**。`wechatCompat.ts` 专门处理微信编辑器导致的样式塌陷和防盗链，这种“脏活累活”的工程化封装具有很高的业务参考价值。
- **信号3：工程化规范且测试完备**。项目不仅使用了现代前端栈（Vite 5 + React 18），还包含了完整的 E2E 测试 (`playwright`) 和单元测试 (`vitest`)，在个人/小型开源项目中较为罕见，代码质量有保障。

### ⚠️ 主要缺点或风险
【INFERENCE】
- **缺点1：图片 Base64 转换存在体积隐患**。为解决防盗链，工具将外链图片转为 Base64。如果文章包含大量高清大图，生成的 HTML 体积会暴增，可能触发微信公众号编辑器隐藏的字符数/体积限制，导致保存失败或页面卡顿。
- **缺点2：缺乏高阶 Markdown 生态支持**。从 `package.json` 来看，依赖仅包含 `markdown-it` 和基础插件，未看到针对数学公式（KaTeX/MathJax）、Mermaid 图表等硬核技术写作所需的扩展。
- **缺点3：主题定制自由度受限**。虽然内置 30 套主题，但项目似乎缺乏让用户直接编写自定义 CSS 或 JSON 来创建专属主题的开放入口，受限于预设。

*对使用场景的影响：技术类博主可能无法渲染复杂的公式和图表；重度图文作者在发布包含数十张高清图的游记时，可能在最后一步粘贴到微信时遭遇浏览器卡死。*
