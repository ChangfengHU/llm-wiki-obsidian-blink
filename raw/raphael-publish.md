### 🎯 一句话定位
一款纯前端的现代 Markdown 排版引擎，核心解决**富文本粘贴净化**与**微信公众号排版（图片防盗链、样式塌陷）**的痛点。

### ⚡ 核心功能
1. **魔法粘贴（富文本转 MD）**：基于 `turndown`，支持将飞书、Notion、Word 或网页的富文本直接粘贴并自动净化为纯 Markdown，支持直接粘贴图片。
2. **微信底层 DOM 适配**：通过 `wechatCompat` 引擎重塑列表、表格和多图网格，解决微信编辑器中常见的样式塌陷和折断问题。
3. **外链图片自动 Base64**：一键复制到公众号时，自动将外链图片转为 Base64，完美绕过微信“此图片来自第三方”的防盗链限制。
4. **开箱即用的高定主题**：内置 30 套（经典/潮流）高度定制的 CSS 样式，覆盖代码块、引用、表格等所有 Markdown 元素。
5. **纯静态与多端预览**：支持手机/平板/PC 实时预览，并提供 HTML/PDF 导出，纯前端架构可零成本部署。

### 🎭 适用场景
- **自媒体跨平台搬运**：在 Notion、飞书或 Word 中写完初稿，直接复制粘贴进该工具，一键排版后发往微信公众号。
- **技术博主发文**：使用 Markdown 撰写包含大量代码块的文章，需要美观的代码高亮和排版样式推送到微信。
- **内容快速存档**：将任意网页的图文内容复制进来，自动转为 Markdown 并导出为 PDF 或 HTML 存档。

### ✅ 是否值得深入研究
**结论：值得（特别是对前端工程师）**

**理由**：
表面上是个常规的 Markdown 编辑器，但其核心价值在于**处理脏数据和特定平台兼容性的工程实践**。
项目采用现代前端栈（React 18 + TS + Vite），代码结构清晰。深入阅读 `src/lib/wechatCompat.ts`（微信 DOM 适配）和 `htmlToMarkdown.ts`（富文本解析）的源码，对于学习 AST 转换、DOM 操作、剪贴板劫持以及前端纯静态工具的架构设计极具参考价值。此外，项目配置了完整的 Vitest 和 Playwright 测试，工程化水平较高。

### ⚠️ 主要缺点或风险
1. **Base64 图片的隐患**：将外链图片转为 Base64 虽然解决了防盗链，但如果文章包含大量高清大图，会导致剪贴板体积过大，可能引起微信编辑器卡顿或粘贴失败。
2. **平台依赖风险**：其核心卖点之一是解决微信公众号的排版兼容性。如果微信官方编辑器进行重大底层 DOM 更新，`wechatCompat.ts` 的规则可能会失效，需要持续跟进维护。
3. **纯前端局限**：没有后端意味着缺乏云端同步和图床管理功能（如果用户想用自己的 OSS），更适合即用即走的轻量场景。

### 🔗 与同类项目对比
*对比目标：Markdown Nice (mdnice), Doocs/md*
- **优势**：技术栈更现代，UI 更加现代化。**“魔法粘贴”（逆向解析富文本）**是其最大差异化亮点；自带的 Base64 转换降低了小白用户配置第三方图床的门槛。
- **劣势**：生态不如 mdnice 成熟。mdnice 拥有庞大的用户自定义主题市场和活跃的社区插件，而本项目目前主要依赖内置的 30 套主题，扩展性略逊一筹。
