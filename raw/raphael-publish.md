### 🎯 一句话定位
【FACT】一款专为微信公众号和内容创作者打造的现代 Markdown 排版引擎，能将富文本或纯 Markdown 转化为完美兼容微信公众号的精美排版。
*来源：GitHub README*

### ⚡ 核心功能
【FACT】
1. **魔法粘贴（富文本转 MD）**：底层借助 `turndown`，支持从飞书、Notion 等平台复制富文本并自动转化为纯净 Markdown，支持直接粘贴图片。
2. **微信环境特化兼容**：一键复制时，外链图片自动转 Base64 绕过微信防盗链，并通过 `wechatCompat.ts` 重塑底层 DOM，防止列表和表格在微信中塌陷。
3. **30套预设高定主题**：内置基于 `Tailwind CSS` 构建的多套排版主题（如 Notion风、少数派风等），覆盖背景、字体、代码块等元素的独立设计。
4. **多端预览与导出**：支持手机/平板/PC 实时预览，并借助 `html2pdf.js` 提供 PDF 和 HTML 导出功能。
*来源：GitHub README / package.json / 代码结构*

【INFERENCE】
**结论**：值得（特别是对于前端工程师和富文本/Markdown 编辑器开发者）

**理由**：
- **信号1：优秀的工程化与代码质量**：项目结构极度清晰，核心逻辑抽离（如 `htmlToMarkdown.ts`, `wechatCompat.ts`），并且配备了完整的单元测试（`*.test.ts`）和 E2E 测试（`playwright`），这在个人开源工具中非常罕见。
- **信号2：精准解决微信排版痛点**：微信公众号后台对外部 CSS 和 DOM 结构极其苛刻。该项目通过内联样式转换、Base64 图片注入、特定的 DOM 重塑（`wechatCompat`）提供了一套完整的微信富文本兼容落地方案，极具参考价值。
- **信号3：现代化的技术栈**：Vite + React 18 + Tailwind CSS 的组合，配合 `framer-motion` 做动画，是学习现代纯前端静态工具站开发的绝佳模板。

### ⚠️ 主要缺点或风险
【INFERENCE】
- **缺点1：Base64 图片转换的体积隐患**：一键复制时将所有外链图片转为 Base64。若文章包含大量高清大图，生成的剪贴板数据或 HTML 会极其庞大，可能导致微信后台粘贴卡顿甚至截断。
- **缺点2：纯前端架构导致的数据丢失风险**：从文件结构看，项目没有后端数据库（纯静态部署）。如果不小心刷新页面或清理浏览器缓存，未导出的草稿可能会丢失（除非实现了完善的 LocalStorage 兜底，但依然不适合做长期内容管理）。
- **缺点3：高度依赖微信编辑器的底层规则**：`wechatCompat.ts` 是针对当前微信公众号编辑器的 Hack 方案。一旦微信官方更新了富文本过滤规则，排版可能会瞬间大面积失效。

**对使用场景的影响**：用户只能将其作为“排版中转站”，而不能作为“主力写作软件”；处理多图长文时需谨慎测试微信的粘贴限制。
