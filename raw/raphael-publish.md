### 🎯 一句话定位
一款专为微信公众号打造的现代 Markdown 排版引擎，能将任意富文本或纯文本丝滑转换为高度定制、防微信吞样式的精美图文。

### ⚡ 核心功能（3~5条）
1. **富文本“魔法粘贴”**：底层集成 `turndown`，复制飞书、Notion 或网页内容粘贴时，自动逆向解析为纯净 Markdown，支持直接粘贴图片。
2. **微信生态深度兼容**：一键复制到公众号，自动将外链图片转为 Base64（解决防盗链报错），并通过底层 DOM 重塑解决微信表格/列表塌陷问题。
3. **高定主题系统**：内置 30 套现代风格主题（如 Notion、Claude、少数派），对背景、字体、代码块等元素进行细粒度控制。
4. **多端预览与导出**：支持手机/平板/PC 实时预览，并集成了 `html2pdf.js` 支持导出 PDF/HTML。

### 🎭 适用场景
- **技术博主/程序员**：需要将含有大量代码块、表格的 Markdown 文章无损发布到微信公众号。
- **新媒体运营**：习惯在 Notion、飞书等现代协作工具中写稿，需要一键转换并排版到微信后台。
- **快速文档生成**：需要通过 Markdown 快速生成排版精美的 PDF 报告或邮件正文。

### ✅ 是否值得深入研究
**值得。** 
特别是对于前端开发者。该项目工程化规范良好（Vite + React 18 + Playwright/Vitest 测试），代码结构清晰。它是学习以下技术的绝佳参考：
1. **剪贴板事件处理**：如何拦截粘贴事件并将富文本/HTML 优雅地转换为 Markdown 抽象语法树。
2. **Markdown 渲染定制**：如何深度扩展 `markdown-it` 插件，实现多图网格等自定义语法。
3. **特定平台的 DOM 黑魔法**：查看 `src/lib/wechatCompat.ts` 可以学到如何通过内联样式和特定的 DOM 结构绕过富文本编辑器的过滤规则。

### ⚠️ 主要缺点或风险
1. **Base64 图片体积炸弹**：将所有外链图片转为 Base64 虽解决了防盗链，但如果文章包含大量高清图，极易触发微信公众号单篇文章的总体积限制，导致保存失败。
2. **强依赖微信编辑器规则**：微信后台若更新 DOM 过滤策略（如禁用某些内联样式），核心的排版兼容逻辑可能瞬间失效，需持续跟进维护。
3. **单页面工具局限**：纯前端无后端设计，不具备文章云端同步、历史版本管理等重度笔记软件功能。

### 🔗 与同类项目对比
- **对比 Markdown Nice (mdnice)**：mdnice 生态庞大但代码较老且商业化严重。本项目完全开源，技术栈更现代（Tailwind + TS），UI 交互更轻量极客。
- **对比 Doocs/md**：Doocs 是经典的开源微信排版工具。本项目在差异化上更胜一筹，尤其是**“富文本逆向转 MD（魔法粘贴）”**体验更好，且内置的主题审美更贴近现代 SaaS 产品（如 Linear、Stripe、Notion 风格），而非传统的公众号大红大紫风格。
