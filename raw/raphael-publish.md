### 🎯 一句话定位
【FACT】专为微信公众号和内容创作者打造的纯前端 Markdown 排版引擎，主打将第三方富文本无缝转换为适配微信公众号的精美排版。
*来源：GitHub README*

### ⚡ 核心功能
【FACT】
1. **魔法粘贴（富文本净化）**：利用 `turndown` 拦截飞书、Notion、Word 的富文本剪贴板，自动转化为纯净 Markdown，支持截图直接粘贴。
2. **微信环境深度适配**：一键复制到公众号时，自动将外链图片转为 Base64（绕过微信防盗链报错），并通过底层 DOM 重塑防止列表/表格在微信中塌陷（`wechatCompat.ts`）。
3. **30 套预设主题**：内置多种高定样式（如 Notion风、微信原生、少数派等），一键切换全局排版风格。
4. **多端预览与导出**：支持手机/平板/PC 实时预览，并可通过 `html2pdf.js` 导出为 PDF 或 HTML。
*来源：GitHub README / package.json / 代码结构*

### 🎭 适用场景
【INFERENCE】
- **微信公众号日常运营**：需要快速将 Markdown 稿件转化为美观的公众号推文，且不想手动处理图片防盗链问题的编辑。
- **跨平台创作者（Notion/飞书用户）**：习惯在 Notion 或飞书中写稿，需要一键将内容搬运至微信公众号发布的用户。
- **技术博主**：需要发布带有代码高亮（`highlight.js` 支持）的技术文章到微信公众号的程序员。

*判断依据：README 明确提及的“魔法粘贴”来源（Notion/飞书）、一键复制到公众号的特性，以及依赖库中的 `highlight.js`。*
*confidence：high*

### ✅ 是否值得深入研究
【INFERENCE】
**结论：值得（特别是对前端富文本处理和微信生态感兴趣的开发者）**

**理由：**
- **信号1：解决了具体的业务痛点**。源码中的 `wechatCompat.ts` 极具参考价值，它展示了如何通过操作 DOM 和 Base64 转换，绕过微信公众号编辑器恶心的“图片防盗链”和“样式塌陷”黑盒限制。
- **信号2：富文本/Markdown 互转的最佳实践**。项目中结合使用了 `markdown-it` 和 `turndown`，其 `htmlToMarkdown.ts` 的实现逻辑对于需要处理复杂剪贴板数据的项目很有启发。
- **信号3：工程化标准高**。作为一个开源工具，不仅采用了 React 18 + Vite 的现代技术栈，还配置了完整的 Vitest 单元测试和 Playwright E2E 测试，代码结构清晰，适合作为学习现代前端工程的范例。

*confidence：high*

### ⚠️ 主要缺点或风险
【INFERENCE】
- **缺点1：高度依赖微信编辑器的底层漏洞/规则**。将图片全量转为 Base64 注入虽然能绕过防盗链，但如果微信公众号后台未来限制单次粘贴的字符体积，或封杀 Base64 图片解析，该核心功能将直接失效。
- **缺点2：纯前端架构导致功能天花板低**。没有后端和数据库，意味着无法实现图床管理、历史文章云端同步、多端数据漫游等重度需求，只能作为单机单次的工具使用。
- **缺点3：不支持复杂的微信 SVG 交互排版**。基于 Markdown 渲染，注定只能做流式排版，无法实现市面上（如 135编辑器）流行的滑动卡片、点击展开等高级交互特效。

*对使用场景的影响：适合个人轻量级、标准化的文字排版；团队协作或追求极致交互特效的公众号运营者无法将其作为主力工具。*
